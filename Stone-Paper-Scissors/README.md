# ✊✋✌️ Rock Paper Scissors — Web Edition

A clean, modern take on the classic Rock Paper Scissors game — built with plain HTML, CSS, and JavaScript. No frameworks, no backend, no build step. Just open and play.

## 🎮 Live Demo

Open `rock_paper_scissors.html` in any browser — that's it.

## ✨ Features

- **Color-coded choices** — Rock, Paper, and Scissors each have their own visual identity
- **Live scoreboard** — tracks wins, ties, and losses in real time
- **Smooth micro-interactions** — a satisfying shake animation on every round
- **Fully responsive** — works on desktop and mobile
- **Accessible** — keyboard navigable with visible focus states, respects reduced-motion preferences
- **Zero dependencies** — pure HTML/CSS/JS, nothing to install

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom properties, animations, grid/flexbox)
- Vanilla JavaScript (no libraries, no frameworks)

## 🚀 Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/naveenkushwaha7804/rock-paper-scissors.git
   ```
2. Open `rock_paper_scissors.html` in your browser
3. Pick Rock, Paper, or Scissors and play against the CPU

## 🧠 How It Works

The game logic runs entirely in the browser:
- The CPU's move is picked randomly using `Math.random()`
- A simple rule lookup (`rock beats scissors`, `paper beats rock`, `scissors beats paper`) decides the winner
- The scoreboard updates instantly using JavaScript DOM manipulation — no page reloads, no server calls
